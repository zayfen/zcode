# 中国象棋游戏 PRD

## 背景
需要开发一个高质量、高仿真的网页版中国象棋（Xiangqi）游戏。

## 需求
1. **界面精美、现代化**：要有立体的木质棋子效果和高质量的棋盘网格，界面设计带有中国古风元素但视觉上要求现代化（例如阴影、纹理效果等）。
2. **基础规则判定**：必须实现中国象棋完备的走子规则和吃子规则：
   - 车走直路、马走日、象飞田、炮翻山。
   - 士在九宫内斜走，将/帅在九宫内直走或横走。
   - 不可“飞象过河”、“马腿被别”、“士出九宫”、“将帅出九宫”。
   - 兵/卒过河前后走法区别（过河前只能向前，过河后可向前或左右横走）。
   - 两将（帅）不能直接照面（白脸将规则）。
3. **交互体验**：
   - 支持双人同机对战模式（轮流发车）。
   - 点击选中棋子后，需要在棋盘上高亮显示该棋子合法的所有落子点。
   - 棋子移动时要有流畅的动画过渡。
4. **技术栈**：
   - 优先使用 React + TypeScript，或者 Vanilla JS + HTML5/CSS3 + Canvas 进行渲染均可。请选用你认为最能体现“精美、仿真”技术的方法。
   - 要有比较好的代码模块划分（如拆分 Rules、Board Component、Game State 等）。
